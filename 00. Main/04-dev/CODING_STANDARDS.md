# Coding Standards

---

## 1. General

- Code dễ đọc hơn code thông minh
- Type rõ ràng
- Không duplicate logic
- Không duplicate UI
- Không over-engineer

---

## 2. UI Rules

- Không hard-code color
- Không hard-code spacing
- Không hard-code radius
- Không hard-code shadow
- Không hard-code animation
- Pages dùng components/patterns
- Components dùng primitives
- Primitives dùng tokens

---

## 3. Component Rules

Mỗi component phải có:
- purpose
- variants
- sizes nếu cần
- states
- accessibility
- tests nếu phù hợp

---

## 4. File Naming

- Components: PascalCase
- Hooks: useSomething
- Utils: camelCase
- Types: PascalCase
