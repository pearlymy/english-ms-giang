# Design Overview

> Tổng quan định hướng thiết kế của project.

---

## 1. Design Goals

- UI đồng nhất
- Dễ dùng
- Dễ mở rộng
- Accessible
- Responsive
- Component tái sử dụng được

---

## 2. Visual Direction

### Brand personality

- Clean
- Modern
- Trustworthy
- Efficient
- Friendly

### Visual tone

| Attribute | Direction |
|---|---|
| Density | Comfortable |
| Contrast | Medium-high |
| Corner style | Soft |
| Motion | Subtle |
| Complexity | Minimal |

## 4. UI Reference Rules

Agent phải dùng ảnh mẫu để suy ra:

- layout
- spacing
- color usage
- typography
- component style
- state
- responsive behavior
- animation feeling

Không được tạo style mới lệch khỏi ảnh mẫu.

---

## 5. Design Principles

- Consistency over creativity
- Reusable component first
- Token-driven UI
- Simple first, scalable later
- Motion with purpose
- Accessibility by default
