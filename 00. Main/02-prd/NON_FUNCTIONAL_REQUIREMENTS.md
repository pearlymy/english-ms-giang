# Non-Functional Requirements

---

## 1. Performance

- Page phản hồi nhanh
- Tránh re-render không cần thiết
- Loading state rõ ràng

---

## 2. Accessibility

- Keyboard navigation
- Focus visible
- Semantic HTML
- Form labels rõ
- Error message rõ
- Không truyền tải thông tin chỉ bằng màu

---

## 3. Responsiveness

- Mobile: single-column
- Tablet: 1-2 columns
- Desktop: grid rõ ràng
- Touch target đủ lớn

---

## 4. Maintainability

- Component hóa rõ
- Không duplicate component
- Không hard-code style
- Feature logic không nằm trong design-system

---

## 5. Security

- Validate input
- Không expose sensitive info
- Không trust client input
- Error message không leak internal detail
