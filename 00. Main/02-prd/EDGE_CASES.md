# Edge Cases

---

## 1. Data States

- No data
- Partial data
- Invalid data
- Slow loading
- Failed request
- Permission denied

---

## 2. User Input

- Required field missing
- Wrong format
- Very long input
- Special characters
- Duplicate submission

---

## 3. System

- Network error
- Server error
- Timeout
- Unauthorized
- Session expired

---

## 4. Responsive

- Small mobile screen
- Long text
- Wide table
- Overflow content
