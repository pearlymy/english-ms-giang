## ⚠️ Các điểm cần chú ý đặc biệt

| Vấn đề | Mô tả | Giải pháp |
|---|---|---|
| **Tạo/xóa user Auth** | Cần `service_role` key, không được để ở frontend | Tạo Supabase Edge Function |
| **Mapping field names** | Code dùng `camelCase`, DB dùng `snake_case` | Map thủ công trong từng API file |
| **`assignedClassIds`** | Hiện lưu trong bài tập, cần chuyển sang bảng `assignment_classes` | Sửa `HomeworkContext` filter logic |
| **Real-time** | Nếu cần cập nhật tức thì khi học sinh nộp bài | Dùng `supabase.channel().on('postgres_changes', ...)` |
| **Loading states** | Khi fetch async, cần thêm `isLoading` cho các context | Thêm `useState(true)` + try/catch trong `useEffect` |
